# Полине, с любовью ♡

Интерактивная открытка: React + TypeScript + Vite, SVG и CSS 2.5D. Без бэкенда.

## Запуск

```sh
npm ci
npm run dev
```

Проверка и production-сборка:

```sh
npm run build
npm run preview
```

## GitHub Pages

1. Загрузите содержимое проекта в GitHub-репозиторий, основная ветка — `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` соберёт и опубликует сайт после push в `main`. Его можно запустить вручную через Actions → Publish birthday card → Run workflow.
4. Адрес опубликованного сайта появится в результате шага Deploy.

Если основная ветка называется иначе, измените `branches` в workflow. Vite использует `base: './'`, поэтому изображения, скрипты и PDF работают под адресом с названием репозитория. Публикация из текущей рабочей папки автоматически не выполнялась.

## Содержимое

- `src/config.ts` — поздравления и пути к фото/PDF.
- `public/assets/photos/` — оригинальные фотографии без обработки лиц.
- `public/assets/certificate.pdf` — предоставленный сертификат; заменяется файлом с тем же именем.
- `public/assets/generated_collages/` — предоставленные коллажи, сохранённые для возможного использования. В открытке использованы исходные фото, чтобы сохранить лица.
- `src/components/` — FortuneTeller, PaperFlap, FortuneContent, PhotoCollage, BakeryScene, GiftCertificate, Illustrations.

Три состояния одного объекта: закрытая гадалка, внутренние клапаны, плоский лист с пекарней. Первое нажатие сразу раскрывает выбранное предсказание, без начальной анимации перемешивания. Предсказания на новый год жизни открываются по одному; кнопка «сложить» возвращает к выбору. Прочитанные отмечены сердечком. После всех четырёх доступен финальный секрет с сертификатом.

Сгибы используют CSS perspective/rotateX, отдельные SVG-грани и изменяющиеся бумажные тени; это управляемая 2.5D-анимация, не физическая симуляция оригами. Есть пропуск длинных анимаций и prefers-reduced-motion. Все кнопки доступны с клавиатуры.

Графика цветов, сердец, лапки, круассана, собак и пекарни нарисована в SVG. Дополнительные ассеты не обязательны. Для более авторской иллюстрации их можно впоследствии заменить. Шрифты загружаются из Google Fonts; при недоступности сети используются системные serif/cursive.

Netlify также поддерживается через `netlify.toml`.
